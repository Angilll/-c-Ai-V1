# Астро

Telegram-бот с астрологическими прогнозами и Таро-раскладами. Работает локально — на вашем компьютере, с локальной языковой моделью (Ollama). Никаких внешних API, кроме Telegram.

## Что умеет
- **Астрологический прогноз** — на основе реальных астрономических данных (Swiss Ephemeris).
- **Таро-расклад** — три случайные карты из колоды Райдера-Уэйта.
- **Интерпретатор расклада** — пользователь сам вводит колоду, расклад, карты и вопрос.

## Как работает
1. Пользователь вводит дату, время и место рождения.
2. Данные сохраняются в `data/user_data.json`.
3. Пользователь выбирает одну из трёх кнопок.
4. Запрос уходит в локальную модель `qwen2.5:7b` через Ollama.
5. Бот отдаёт ответ.

## Требования
- Python 3.10+
- Ollama с моделью `qwen2.5:7b`
- Swiss Ephemeris (файлы `.se1` в `ephe/`)
- Telegram Bot Token

## Установка
1. `git clone ...`
2. `pip install -r requirements.txt`
3. `ollama pull qwen2.5:7b`
4. Вставить токен в `fenix.py`
5. `python fenix.py`
